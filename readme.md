# Java ATM System

A console-based ATM application developed in Java to practice Object-Oriented Programming and Exception Handling.

## Features

- Deposit money
- Withdraw money
- Check account balance
- Input validation
- Custom exception handling
- Menu-driven interface

## Concepts Practiced

- Object-Oriented Programming
- Encapsulation
- Constructors
- Exception Handling
- Custom Exceptions
- throw & throws
- Scanner
- Loops
- Switch Statements

## Project Structure

```
ATMSystem/
├── Account.java
├── ATMApp.java
└── InsufficientBalanceException.java
```
