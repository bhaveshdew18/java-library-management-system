# Java Library Management System

A console-based Library Management System developed in Java to practice Object-Oriented Programming (OOP), collections, and modular application design.

## Features

- Display all books
- Search books by ISBN
- Borrow a book
- Return a book
- Track book availability
- Menu-driven console interface

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation
- Constructors
- Getter and Setter Methods
- Methods and Method Decomposition
- ArrayList
- Searching Objects
- Loops
- Switch Statements
- Scanner for User Input

## Project Structure

```text
LibraryManagementSystem/
├── Book.java
└── LibraryManagementApp.java
```

## How to Run

### Compile

```bash
javac *.java
```

### Run

```bash
java LibraryManagementApp
```
